# Codex independent design, 2026-10-31

Written before reading the new Claude consultation response. Prior Claude positions were retained verbatim in claude_prior_positions.md. This is primary-agent design input, not independent approval.

Sam requested a comprehensive extension of non-tree development. Treat coverage of representations, optimization and ensemble contribution as the unit of work. A model name with one weak default run is insufficient coverage. Give the major architectures meaningful fixed initial batches, followed by a common evidence-driven expansion rule. TabM with numerical embeddings, MLP, ResNet, FT-Transformer, RBF SVM and TabR deserve explicit tasks. Kernel approximations, Gaussian processes, smooth models, metric learning and statistical baselines deserve scoped tests and honest feasibility statuses. Feature opportunities from the handoffs remain named experiments.

The central infrastructure issue is ownership of raw rows. A target encoder fitted before a neural stopping split or a calibration split leaks labels into that inner decision even if the outer fold is isolated. The new wrappers must rebuild the complete feature pipeline within every actual fit and discard the stopping-stage state before refitting. Reference/query boundaries for retrieval need equivalent treatment. Supervised preprocessing must not reveal a training query's label through a retrieved neighbour. Freeze a testable contract before implementing these changes.

Use the existing 15 grouped folds. Keep the old ensemble E and original anchor H as immutable comparison references, with separate comparisons for architecture, features and blend contribution. Search estimator seed 0, then confirm nominated recipes on seeds 0, 1, 2 and the averaged policy. A fixed trio of blend weights against E gives contribution evidence for every complete candidate, including weak standalone candidates. No leaderboard-based pruning. A fresh outer split is a stability check conditional on an already explored dataset, not an independent estimate of the whole search.

Measure full-route fit time, stopping and calibration multipliers, memory and repeatability. Initial coverage counts are scientific coverage targets, not permission for unbounded compute. Reserve confirmations, replay, revised-menu evaluation, review and submission preparation before expanding searches. No method is reported as rejected if its coverage was cut for time. The final menu should limit the number of new atomic recipes and favour inexpensive fixed blends first; learned combiners require a separate complete nested cost projection.

Preserve historical artifacts and the current usable candidate. New features and adapters have new recipe and source identities. Before phase 3, replay every atom needed for deployment under the final sources. Method review precedes dependent tuning; this turn delivers the reviewed plan only.
