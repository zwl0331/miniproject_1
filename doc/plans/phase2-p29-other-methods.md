## 6. Isolation contracts that must precede tuning

### 6.1 Neural stopping and final refitting

Each fit receives only raw training rows D, labels, primary groups and a deterministic context. Choose one validation part from five stratified group folds of D using a fixed context seed. On S, the stopping-training part, rebuild feature transformations, including encoder cross-fitting and embedding bins. Transform V, the stopping-validation part, with S's state only. Optimize on S; choose the epoch using V. The outer validation rows are unavailable.

Discard the stopping model, optimizer, preprocessing, encoders, bins and retrieval memory. Rebuild all transforms on D; cross-fit D's supervised training features; initialize a fresh model and refit for the chosen epoch count. The exact epoch-to-update policy is saved. The default keeps the existing epoch-based refit policy and reports the larger final update count. A step-based variant is a separate recipe. Predictions on outer validation/query rows use only the state fitted on D.

The boundary cases are explicit: a stopping-training row uses features cross-fitted within S with its own group excluded and contributes its label to optimization; a stopping-validation row uses S-fitted features and contributes its label only to the stopping metric; an outer-validation row uses D-fitted features and its label is never read. This requires a new raw-row adapter. Passing D-wide precomputed target encodings to the old TabM stopping wrapper is forbidden. Preserve the old adapter for historical recipes. Before new scores, run each of the three P2.5 timing recipes through both old and new adapters on arm B, on all 15 folds. Require predictions on validation and test rows to agree within 1e-12, with identical input layout, preprocessing, contexts, initialization and epoch policy. Also replay the old adapter against its historical banks. Passing only the untouched old path is insufficient. Repeat this gate after a material adapter change. Apply the same contract inside calibration, stacking, and the revised nested evaluator. Receipts identify row sets, groups, transform hashes, stopping losses, chosen epoch and final updates. Structural receipt validation is implemented, including the deferred P2.5 receipt check.

### 6.2 Margin-model calibration

Disable SVC's internal probability fitting. Inside D, build explicit five-fold grouped calibration splits. For each split rebuild the complete base recipe, including all features and supervised encoders, on its calibration-training part; predict raw class-1 margins on its held-out part. Fit a fixed regularized sigmoid to those out-of-fold margins and D's labels. Refit the complete base recipe on D and apply that sigmoid to query margins. The resulting training-size mismatch is assessed by evaluating the entire procedure on outer folds. Initial sigmoid: L2 logistic regression on one margin feature, C=1, solver=lbfgs, tol=1e-8, max_iter=1000, unpenalized intercept, no class weights. Standardize the margin using only the calibration out-of-fold training margins and save that scaler. Record the slope and class orientation; reject nonconvergence. No isotonic search in the initial batch.

Use the same procedure for kernel-ridge scores and linear SVM when they enter probability blending. No global out-of-fold calibrator may be scored on the rows used to fit it. A fitted outer-training feature matrix must not be reused across calibration folds. Include the five calibration fits plus final fit in timing and recipe identity. Native probability models use their native probabilities initially. Never normalize scores using test or validation score distributions.

### 6.3 Retrieval and metric learning

Memory contains only the current permitted training population. During training, exclude every row of the query's primary group from retrieved candidates, not just the exact row. Stopping queries retrieve only S; outer queries retrieve only D. Fitted scaling, NCA/PCA, neighbour indices and neural retrieval parameters are rebuilt within their training boundary. When training query features or retrieved memory features use target encodings, exclude the query's whole group from every encoding dictionary that could reveal its label through the memory. A concrete safe implementation is group-held-out query blocks with their reference memory and all encoders fitted on the complementary groups. Freeze that policy, its inference memory rule and measured cost before the D-arm run. An unsafe shortcut is not an admissible D-arm.

With the query-block assignment fixed, a construction-level own-group test must detect training self-retrieval before the query loss is used. Also test the indirect target-encoding route. Reject query rows or group IDs injected into a memory manifest. Record candidate exclusions and memory hashes. For the block construction, a training query in block b retrieves only S minus b with transforms fitted there; a stopping query retrieves from all S; an outer query retrieves from D. The larger inference memory is an accepted training-size mismatch evaluated as part of the complete procedure. A positive control flips a permitted memory label and verifies its label input and relevant target-encoded values change, using a fixture with nonzero relevant counts. No retrieval from test rows, external song catalogs or pretrained embeddings.

### 6.4 Verification and resources

Required tests include held-out-label flips with fixed split assignments; poisoning a held-out feature to expose preprocessing fitted on the wrong population; wrong-group calibration; a deliberately leaky target-encoding path; self-group and indirect retrieval; stale or malformed stopping receipts; class-1 score orientation; fixed-seed replay; and end-to-end prediction through the deployment adapter. The negative tests must fail on the known-wrong variants. An outer-validation label flip must leave all training decisions and its predictions unchanged when assignments are fixed. For the stopping test, inject and hold fixed both the S/V assignment and S's encoder folds. Flipping V labels must leave S's and V's feature matrices, fitted preprocessing/encoder state, the split receipt and the stopping network trajectory unchanged up to a common fixed epoch horizon. Stopping losses, stopping time, chosen epoch and final refit may change. Use fixed-epoch diagnostics rather than comparing trajectories past an early stop. A positive control flips a permitted S label in a constructed shared-date case and verifies affected target-encoded values change while V's unsupervised date counts do not. A retrieval self-label test holds model weights and other labels fixed and checks constructed query/memory inputs before the query loss is used; it does not demand that a retrained supervised model ignore training labels. Poisoning held-out feature values tests invariance of fitted training state, not invariance of that query's prediction. Test the complete path, not only a standalone transform.

## 8. Allocation, refinement and seed confirmation

Complete the initial coverage and required representation comparisons before performance-based pruning. Earlier P2.5 thresholds do not terminate this new neural search after a few raw-input trials. Do not demand +0.003 against E before allowing any investigation; that would hide smaller useful contributions.

After initial coverage, nominate two distinct recipes per family: highest standalone mean fold AUC, and greatest gain over E at one of the three declared blend weights. Exact duplicate nominations merge. Ties use unrounded scores then canonical recipe ID. A within-family rank is not an independent validation result.

The six core families receive their first eight-configuration diagnostic/refinement batch without a performance gate once their initial coverage is complete and the reserved cost is admitted. A specific optimization rescue occupies this first batch rather than adding another one. It cannot be repeated indefinitely. Other families receive a first eight-configuration refinement only if their remaining ceiling admits all eight, and if: (a) their best blend improves E by at least 0.0005 on average and is positive on at least two repeats; (b) they rank among the top two completed P2.9 families by standalone score and are within 0.002 of the best completed P2.9 standalone (trees excluded from this exploration-only ranking); (c) a matched representation improves their prior control by at least 0.003 on average and is positive on at least two repeats; or (d) a specified optimization defect or search-boundary optimum needs one declared rescue. Freeze the correction before fitting. Positive on two rather than all three repeats deliberately relaxes the old exploration-allocation heuristic; it does not relax the final selection/deployment rule. A confidence interval excluding zero is not required for allocation.

After the first admitted refinement, initialize a two-batch continuation allowance. Qualifying progress resets it to two; an additional batch without progress consumes one, and zero stops expansion. Qualifying progress means at least 0.0005 improvement in the family's best contribution to E; or at least 0.001 in its best standalone while within 0.002 of the best completed P2.9 standalone; or a trajectory improvement of at least 0.003 in standalone between consecutive batches with positive gains on at least two repeats.
