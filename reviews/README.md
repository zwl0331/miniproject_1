# Review records

Each file here is one review unit, named `YYYY-MM-DD-<slug>.md` and appended to round by round.

- **Template:** the cross-review skill's `templates/request.md`.
- **Who writes what:** the author writes each `## Round N: review request`, and `review.sh` appends the reviewer's verdict verbatim, followed by a `Reviewer run:` line.
- **No review needed:** these records are exempt from review.
- **Older records:** the records up to P2.4 round 4 (2026-10-28 to 30) follow `../doc/review_policy.md`, with revision fingerprints from `../tools/fingerprint.py`.
